3. PM Reassignment: Fix Idempotent Check & Query
--------------------------------------------------
- Fix bug: idempotent check hanya cek record dengan status "menunggu" → diganti cek record apapun (termasuk "disetujui", "ditolak")
- Fix bug: query reassignment hanya ambil log dengan status "menunggu_pm" (tidak termasuk "menunggu_hr")
- Log dengan status "menunggu_hr" sudah lewat tahap PM → tidak disentuh saat edit PM
- PM yang sudah pernah approve tidak akan bikin record baru saat di-add-back (idempotent)
- PM yang belum approve dan di-remove → record "menunggu"-nya dihapus, PM baru gantikan posisi

File yang diubah:
- app/services/hr_service.py - rewrite pm_add logic:
  - Loop per new_pm_id (bukan per log_id dengan first_new_pm)
  - Idempotent check: cek record apapun (bukan cuma "menunggu")
  - Query: status == "menunggu_pm" saja (bukan "menunggu_hr")
  - Buat record baru untuk setiap PM baru (bukan reassign dari PM lain)
