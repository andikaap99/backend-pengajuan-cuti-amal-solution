Changelog - 22 September 2026

1. Fitur Forgot Password (Reset Password via Email)
----------------------------------------------------------
- Tambah tabel baru `password_reset_tokens` untuk menyimpan token reset password
- Token di-generate menggunakan `secrets.token_urlsafe(32)`, berlaku 30 menit, bisa dipakai 1 kali
- Dua endpoint baru:
  - `POST /auth/forgot-password` - Kirim link reset password ke email (anti enumerasi: response sama untuk email ada/tidak ada)
  - `POST /auth/reset-password` - Validasi token dan update password baru
- Halaman reset password HTML di `GET /auth/reset-password-page` dengan desain clean modern (logo AjuanCuti, Inter font, warna navy)
- Email notifikasi: link reset password + konfirmasi password berhasil diubah

File baru:
- app/models/password_reset_token.py - Model SQLAlchemy `PasswordResetToken`
- templates/reset_password.html - Halaman reset password (Jinja2 + JavaScript)

File yang diubah:

- app/models/user.py - Tambah relationship `password_reset_tokens`
- app/core/config.py - Tambah `BACKEND_URL` dan `FRONTEND_URL`

- app/services/email_service.py - Tambah `send_forgot_password_email()` dan `send_password_changed_notification()`

6. Sistem Cuti: Individual Dates (Bukan Range)
----------------------------------------------------------
- Ganti sistem cuti dari range tanggal (`tanggal_mulai`-`tanggal_selesai`) menjadi list tanggal individual
- Misal cuti tanggal 12 dan 14 = 2 hari (bukan 3 hari seperti sebelumnya)
- Tabel baru `log_cuti_dates` menyimpan setiap tanggal cuti sebagai record terpisah
- Durasi dihitung dari `len(tanggal_list)` bukan `(end - start).days + 1`
- Validasi overlap sekarang cek per tanggal individual, bukan range
- "Sedang cuti" check juga pakai individual dates
- Input dari FE: `{ "tanggal": ["2026-09-12", "2026-09-14"], ... }`
