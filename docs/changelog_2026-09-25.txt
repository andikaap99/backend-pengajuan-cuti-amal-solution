7. Fix Hapus Karyawan: Error IntegrityError 1048
----------------------------------------------------------
- `DELETE /hr/karyawan/{id}` error: `Column 'id_user' cannot be null` pada `password_reset_tokens`
- Penyebab: `delete_karyawan` lupa menghapus `password_reset_tokens` → SQLAlchemy men-null-kan FK (kolom NOT NULL)
- Fix: hapus token milik user sebelum `db.delete(user)` (pola sama seperti anak lain)

File yang diubah:
- app/services/hr_service.py - import PasswordResetToken + hapus token sebelum hapus user
