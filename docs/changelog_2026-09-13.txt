Changelog - 13 September 2026
============================

1. Pengajuan Kerja: Approval Flow Sama dengan Cuti
---------------------------------------------------
- Flow lama: semua role selalu `menunggu_pm` → `menunggu_hr` → `disetujui_hr`
- Flow baru: menggunakan `get_ongoing_statuses(user)[0]` (dynamic per role)

| Role Pengaju | Flow |
|---|---|
| Karyawan dept≠1 | menunggu_pm → menunggu_hr → disetujui_hr |
| Karyawan dept=1/PM | menunggu_hr → disetujui_hr |
| HR / staff_hr | menunggu_hr → menunggu_direktur → disetujui_hr |
| Direktur | ❌ Tidak boleh mengajukan |

File yang diubah:
- app/services/penambahan_kerja_service.py - `create_penambahan_kerja()` pakai dynamic status, conditional PM record creation, email notif per role flow
- app/routers/karyawan.py - role restriction: `karyawan` → `karyawan, pm, hr, staff_hr`


2. Direktur Approval untuk Penambahan Kerja
--------------------------------------------
- HR approve (submitter HR/staff_hr) → `menunggu_direktur` (bukan langsung FINAL)
- Direktur approve → `disetujui_hr` (FINAL) + isi `diproses_hr` dan `keterangan_disetujui_hr`
- Queue direktur: filter status `menunggu_direktur`

File yang diubah:
- app/services/penambahan_kerja_service.py - tambah `process_penambahan_kerja_direktur()`, update `process_penambahan_kerja_hr()` untuk handle HR→Direktur path
- app/routers/approval.py - tambah `direktur` ke role check, import `process_penambahan_kerja_direktur`, import `get_penambahan_kerja_queue_direktur`
